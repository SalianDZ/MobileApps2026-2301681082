**📍 Spotter - Your Personal Location Tracker 🌍✨**

A beautifully designed, modern Android application built with Kotlin that lets you save, explore, and manage your favorite spots. Whether it's a hidden hiking trail, a cool cafe, or a scenic viewpoint, Spotter helps you keep track of it all with personal photos, notes, and exact GPS coordinates!
Built with a focus on clean architecture and premium UI/UX, this app demonstrates the power of modern Android development. 🚀

**✨ Key Features:**

📸 Photo Integration: Capture and save photos directly within the app using the device's camera.
🗺️ GPS Location Tracking: Automatically fetch and store exact geographic coordinates (Latitude & Longitude) using hardware sensors.
🧭 Google Maps Navigation: Open any saved location directly in Google Maps with a single tap.
🎨 Premium Material 3 Design: A luxurious, intuitive UI featuring overlapping cards, floating action buttons (FAB), pill-shaped buttons, and a beautiful grid layout.
🌙 Dynamic Dark Mode: Fully responsive design that adapts perfectly to system-wide light and dark themes.
🎬 Smooth Animations: Elegant screen transitions and dynamic layout changes for a polished feel.
🔄 Full CRUD Functionality: Create, Read, Update, and Delete locations effortlessly (including intuitive swipe-to-delete!).
🛠️ Tech Stack & Architecture

This project is built using industry-standard tools and practices:
Language: Kotlin 
Architecture: MVVM (Model-View-ViewModel) for a robust and testable codebase 🏗️
Database: Room Database for persistent, offline local storage 🗄️
Navigation: Android Jetpack Navigation Component with custom transition animations 🚀
UI Components: Material Design 3, ConstraintLayout, RecyclerView (Grid), and ShapeableImageView 
Hardware APIs: FusedLocationProviderClient for location services and internal file storage for image management 📷
